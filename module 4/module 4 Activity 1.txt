 module 4 Activity 1: Component Creation Workshop
1. Aim

To design and develop reusable UI components and understand how component-based architecture improves the organization, maintainability, and reusability of web applications.

2. Introduction

A UI component is a small, independent part of a webpage that performs a specific function. Instead of creating the same interface repeatedly, developers can create a component once and reuse it wherever required.

Examples include:

Navigation bars
Cards
Forms
Modal windows
Dashboard widgets
3. Component-Based Architecture

Component-based architecture divides an application into smaller, independent components.

Each component:

Performs a specific function.
Can be developed and tested separately.
Can be reused in different parts of an application.
Makes the application easier to maintain.
4. Navigation Bar

A Navigation Bar provides links that allow users to move between different pages or sections.

It may contain:

Home
About
Services
Contact
Login/Logout

A reusable navigation component can be included on multiple pages.

5. Cards

A Card is a UI container used to display related information in a structured format.

Cards can be used for:

Products
Student details
Blog posts
User profiles
Course information

The same card component can display different data.

6. Forms

Forms are used to collect information from users.

Examples:

Registration form
Login form
Feedback form
Contact form
Search form

A reusable form component reduces repeated code and provides consistent design.

7. Modal Windows

A Modal Window is a popup interface that appears above the main webpage to display information or request user input.

Examples:

Login popup
Confirmation message
Delete confirmation
Edit form
Alert message

The same modal component can be reused for different purposes.

8. Dashboard Widgets

Dashboard widgets are small UI components that display specific information or statistics.

Examples:

Total Users
Total Orders
Revenue
Completed Tasks
Notifications

Each widget can be designed as an independent reusable component.

9. Reusability

Reusability means creating a component once and using it multiple times.

For example, a single Card component can display different students:

Card Component → Student 1
Card Component → Student 2
Card Component → Student 3

Only the data changes while the component structure remains the same.

10. Technologies Used
HTML – Creates the structure of components.
CSS – Provides styling and responsive design.
JavaScript – Adds functionality and interaction.
React.js – Provides a component-based approach for building modern web interfaces.
11. Implementation Process

The activity can be performed using the following steps:

Identify commonly repeated UI elements.
Divide the interface into individual components.
Create separate components for the navigation bar, cards, forms, modals, and widgets.
Add styling and functionality.
Pass different data to reusable components.
Combine the components to build the complete webpage.
Test each component individually and as part of the application.
12. Learning Outcome

Students will be able to:

Understand component-based architecture.
Design reusable UI components.
Create structured and maintainable interfaces.
Reduce code duplication.
Understand how components can be combined to build larger applications.
Develop a better approach to modern frontend development.
13. Conclusion

The Component Creation Workshop helps students understand how modern web applications are divided into small, reusable UI components. By creating navigation bars, cards, forms, modal windows, and dashboard widgets, students learn how component-based architecture improves reusability, maintainability, and development efficiency.
