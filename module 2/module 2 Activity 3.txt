 module 2 Activity 3: DOM Manipulation Workshop
1. Aim

To understand and implement DOM (Document Object Model) manipulation to dynamically update webpage content based on user actions.

2. Introduction

The DOM is a programming representation of an HTML document. It allows JavaScript to access, modify, add, or remove HTML elements and their content dynamically.

3. Document Object Model (DOM)
The DOM represents a webpage as a tree structure of elements.
Each HTML element is treated as an object that JavaScript can access and modify.
It enables webpages to respond dynamically to user interactions.
4. Selecting HTML Elements

JavaScript can select elements from a webpage using methods such as:

getElementById()
getElementsByClassName()
querySelector()
querySelectorAll()

These methods allow JavaScript to identify specific elements for modification.

5. Modifying Content

Students can dynamically change webpage content using JavaScript.

Examples include:

Changing text using textContent.
Changing HTML using innerHTML.
Changing styles using the style property.
Changing element attributes.
6. User Actions and Events

DOM manipulation commonly works with events generated by user actions.

Examples:

Button clicks
Form submissions
Mouse movements
Keyboard input
Checkbox selection

JavaScript event listeners can detect these actions and execute specific functions.

7. Dynamic Updates

Students can modify a webpage without refreshing the entire page.

Examples:

Display a message when a button is clicked.
Change the background or text color.
Add a new item to a list.
Remove an existing item.
Display submitted form information.
8. Form Submission

When a user submits a form:

JavaScript captures the submission event.
The entered data is retrieved.
The required validation or processing is performed.
The webpage is dynamically updated with the result.
9. Technologies Used
HTML – Creates the webpage structure.
CSS – Provides styling.
JavaScript – Handles events and performs DOM manipulation.
10. Testing

Students test the webpage by performing different actions such as:

Clicking buttons.
Entering text.
Submitting forms.
Adding and removing items.
Checking whether the webpage updates correctly.
11. Learning Outcome

Students understand how JavaScript interacts with HTML elements and learn to create dynamic and interactive webpages using DOM manipulation and event handling.

12. Conclusion

This activity helps students understand how webpages can respond to user actions without requiring a complete page reload. By using DOM methods, JavaScript events, and dynamic content updates, students can create more interactive and user-friendly web applications.
